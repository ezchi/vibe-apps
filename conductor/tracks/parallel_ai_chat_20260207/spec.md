# Specification: Parallel AI Chat Core UI

## Goal
Create a functional web-based UI for comparing multiple LLM responses side-by-side using mocked data.

## Requirements
- **Multi-Column Layout:** Side-by-side display of LLM responses on desktop; responsive tabbed or stacked view on mobile.
- **Mock Integration:** Simulate responses from ChatGPT, Gemini, and DeepSeek.
- **Model Management:** UI to add or remove specific models from the current view.
- **Export:** Button to download the current chat history as a JSON file.
- **Aesthetic:** Glassmorphism UI using Tailwind CSS.
